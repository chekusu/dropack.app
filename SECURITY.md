# Security

This repository is a static website with a small Cloudflare Worker that adds byte ranges to
MP4 responses (`worker/`). It has no accounts, forms, cookies or server-side data.

If you find a security problem, for example in the Worker, the headers in `public/_headers` or
the build, please report it privately: use **Report a vulnerability** on this repository's
Security tab on GitHub. Please do not open a public issue with the details. If private
reporting is not available, open an issue that only asks for a private contact, without
details, or use the contact form linked from https://dropack.app/support/.

Problems in the iOS app belong to https://github.com/chekusu/dropack.
